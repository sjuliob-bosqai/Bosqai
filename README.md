# BOSQAI Arch-Core · House of Poetry

**Sistema de trabajo** para el concurso arquitectónico House of Poetry (YAC): agenda y tareas editables, Pomodoro 25/5/15, búsqueda de hallazgos con procedencia y biblioteca crítica de tres volúmenes ACY con 19 fichas documentadas.

## Uso en PC y Samsung S23

Abrir `index.html` desde una publicación GitHub Pages cuando esté habilitada. Menú móvil, tarjetas fluidas, controles táctiles y áreas seguras para Samsung S23. El navegador conserva tareas, notas y sesiones de concentración *en ese dispositivo*.

**Trasladar el avance entre PC y celular:** pulsar `Descargar copia JSON` e importar el archivo en el otro navegador. No hay sincronización automática.

## Estructura

- `index.html`: agenda, tablero, Pomodoro, roadmap, estrategias, buscador y archivo.
- `biblioteca/acy-2020.html`, `acy-2021.html`, `acy-2022.html`: páginas de lectura con páginas PDF identificadas.
- `data.js`: fichas, fuentes, tareas y hallazgos.
- `style.css`: diseño adaptable para escritorio y 360 CSS px.
- `app.js`: interacción; no utiliza rastreadores ni servicios externos.
- `sw.js`: soporte de navegación offline tras primera visita HTTPS, sujeto al navegador.
